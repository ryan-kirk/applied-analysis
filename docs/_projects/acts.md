## Goal

Bible Time & Place Explorer is designed to help users explore biblical events across time and place while keeping the visible claims traceable to canonical text, source records, and explicit uncertainty.

## Functionality

Based on the current public README, the application already supports a real multi-view exploration workflow centered on the books of Acts and Luke.

Current functionality includes:

- a searchable event explorer with shared event selection across views
- timeline, map, people, and sources exploration surfaces
- journey overlays and route inspection for event travel sequences
- source-grounded event inspection with citations and external attestation context
- book-scoped filtering across a merged Luke-Acts library

## Technical Capabilities

The public repository indicates the following technical capabilities:
