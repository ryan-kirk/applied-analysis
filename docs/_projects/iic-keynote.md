## Goal

From Signals to Decisions packages a live presentation, supporting visual assets, and export tooling into a single project so the same source material can power both a web presentation and a PowerPoint deck.

## Functionality

The public README describes the repository as an interactive deck system rather than a static slide folder.

Current functionality includes:

- an interactive web deck with keyboard and on-screen navigation
- structured slide content that feeds both web and PowerPoint outputs
- chart and asset export workflows for presentation packaging
- a deployment path for the public presentation experience

## Technical Capabilities

The repository currently appears to include:

<ul class="capability-list">
  <li>TypeScript and front-end application code for the live presentation layer</li>
  <li>Scripted PowerPoint export and chart generation workflows</li>
  <li>Content-driven presentation architecture with deck structure stored as code</li>
  <li>Containerized static deployment support for publishing the deck</li>
</ul>
